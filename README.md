# Alinawaz Wiki Portfolio

Wikipedia-inspired engineering encyclopedia portfolio built with React + Vite.

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Customize
- Update profile URLs and personal details in `src/main.jsx`.
- Add a real profile photo by replacing the `AH` avatar placeholder.
- Add `public/resume.pdf` to enable the Resume download button.
- CppRest links to the public `cppRest` repository. Update the Fleetwise repository link if you want to add its exact public repository URL.
- The LeetCode panel intentionally links to the live profile rather than showing unverified ranking/contest metrics.

## Notes
The content in experience, projects, skills, and education is based on the supplied resume. LLD, HLD, SOLID, design patterns, and distributed-systems sections are educational knowledge articles, not claims of professional project delivery.
